# Lighting image

`potsdamer_platz_1k.hdr` lights the 3D viewport (reflections on metal and
glass). It is "Potsdamer Platz" from [Poly Haven](https://polyhaven.com/a/potsdamer_platz),
released under [CC0](https://polyhaven.com/license): public domain, free to
redistribute.

It is kept in the repository, not fetched from a CDN, so the app works on a
network with no access to the internet.
